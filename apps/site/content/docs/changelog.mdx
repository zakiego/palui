Palui Agent uses [semantic versioning](https://semver.org). Each release is a git tag `vX.Y.Z` on `main`, and a running install reports its version as `version` in `GET /health`.

- While the version starts with `0.`, the v1 scope below is still being built. A minor bump (`0.2.0`) adds features or changes behavior. A patch bump (`0.1.1`) only fixes things.
- `1.0.0` is the release where the v1 scope is done. From then on, a major bump means you have to do something when you upgrade, and the release notes say what.
- Each release groups its changes by feature. Changes that need action from you on upgrade come first, under "Breaking".
- Each entry ends with the PR that made it. "Adds a migration" means rolling back past that release needs the pre-deploy snapshot.

## Unreleased

### Chat

- Fixed: WhatsApp contact cards, locations, polls and captionless videos reach the agent as text, with the contact's number, instead of being dropped. ([#149](https://github.com/zakiego/palui/pull/149))
- Fixed: A message isn't dropped any more when the model can't be reached for a moment. When a turn fails for a temporary reason (network or TLS timeout, rate limit, an overloaded provider, or the model connector still starting after a restart), the agent keeps the message and tries again after 20 s, 1, 2 and 5 minutes, and right away when a connector comes back on. The first retry is silent, the second sends one "pesannya aku simpan" notice, and the answer quotes the original message in a group. A message that arrives in the meantime is answered in the same reply. It gives up with the usual notice after 4 retries or once the message is 15 minutes old, a message still waiting at a restart is answered after the restart, and permanent errors (bad request, auth, exhausted quota) or a turn that already changed data are never retried. ([#147](https://github.com/zakiego/palui/pull/147))
- Fixed: Your own agent transcribes your voice notes again once a Voice connector is on. Adds a migration. ([#150](https://github.com/zakiego/palui/pull/150))
- Fixed: A voice note that can't be transcribed tells the agent why, with the dashboard link to fix it, and keeps the audio. Temporary provider errors are retried. ([#150](https://github.com/zakiego/palui/pull/150))
- Fixed: The agent no longer tacks a list of what the last update changed onto unrelated replies. ([#150](https://github.com/zakiego/palui/pull/150))

### Tools

- Added: Chat history's `search_this_chat` lets an agent find something said earlier in the same chat, groups included, before saying it can't see it. ([#149](https://github.com/zakiego/palui/pull/149))

## Not in v1

These are planned for later and are not part of v1:

- Group chats. The code path exists, but the UI is hidden.
- Voice replies (text to speech). v1 has voice input only.
- stdio MCP servers, a shell tool and a browser tool. They need binaries in the container and a sandbox.
- Subagents.
- Self-written skills.
- Multiple profiles or agents.
- Multiple users.
- A native app.
