Kind: `channel`. The web chat lives in the dashboard on the Chats page, as the chat named "Palui (web)". It goes through the same router and the same agent turn as Telegram and WhatsApp. It's there so you can test without a phone.

## Connect

Nothing to set up. Sign in to the dashboard at `/app` with your passkey, open Chats and pick "Palui (web)". Being signed in is what makes you the owner here.

## How it behaves

- Replies stream in as the model writes them.
- Tool calls show inline, collapsible, with their class badge and duration.
- Pending approvals show Approve and Deny buttons. You can also answer approvals from other channels here.
- Commands work the same as on other channels: `/new`, `/stop`, `/status`, `/connectors`.
- The Chats page also shows your Telegram and WhatsApp chats, but you reply to those from the phone. The input belongs to the web chat.

## Settings

None.

## Tools

None. The web chat is a channel.

## Pause and remove

The web chat is part of the dashboard. Because the dashboard counts as a reachable channel, it's what lets you run `/connectors off telegram` from Telegram itself: you can always turn Telegram back on from the dashboard. See [Chat commands](/docs/chat-commands).
