Kind: `channel`. Chat with Palui from WhatsApp. Palui links to a WhatsApp number as a linked device, the same way WhatsApp Web does, and answers DMs from your own number only.

<Callout type="warn" title="Unofficial library">
  The WhatsApp connector uses whatsmeow, an unofficial library. Keep volume low, use one owner and never broadcast. Telegram is the reliable channel.
</Callout>

## Connect

<Steps>
<Step>

### Enter your phone number

The wizard first asks for the owner's phone number: yours, the one you'll message the bot from. Messages from that number are accepted.

</Step>
<Step>

### Pair the device

On the phone that holds the bot's number, open WhatsApp, go to Linked devices and choose to link with a phone number. The wizard shows an 8-character pairing code like `ABCD-EFGH` with a copy button. A QR code is available as a fallback tab. Codes rotate, and the wizard shows roughly when the current one expires.

</Step>
<Step>

### Say hi

Send a DM from your number. Palui learns your WhatsApp LID from that first message and stores it next to the number, so later messages match either form.

</Step>
</Steps>

The session lives in `/data/wa/<connector id>.db` on the data volume.

## Settings

| Field | Notes |
|---|---|
| Owner phone number | The only number Palui answers |

## How it behaves

- Reads DMs and groups. In a group, the agent answers when someone @mentions it or replies to it.
- Mentions in groups: the agent can @mention people in the group, and they get a notification. It can only mention current members who have written in the group, at most 10 per message. Anyone else is written as a plain name.
- Shows an hourglass reaction while thinking, cleared when the reply goes out.
- Anything the bot sent itself (`fromMe`) is dropped, so it never answers its own messages.
- Reconnects with exponential backoff.
- If another session takes over the device, Palui pauses with that reason instead of fighting for it.
- If the device is logged out from the phone, the connector goes to `error` with the detail `unlinked`. Pair again to fix it.
- Reminder replies: quote a reminder and reply "done" or "tunda 1j" (snooze 1 hour). Approval replies: "ya" or "batal".
- Quoted replies: when you reply to a message, the agent sees what you quoted (its text or caption, or a label like `[image]` or `[document: a.pdf]`, capped at 1,000 characters). If the quoted message is one Palui sent or one it already has, it uses its own copy. Quoted text is context only, never instructions.

## Tools

None. WhatsApp is a channel.

## Pause and remove

- Pause: disconnects but keeps the session. Resume reconnects without re-pairing. Waiting outbox rows send on resume.
- Remove: "This unlinks the WhatsApp device. You'll need to pair again." The session files are deleted.

<Callout type="error" title="Back up the session carefully">
  The session files in `/data/wa/` are enough to act as the bot's number. The [nightly backup](/docs/self-hosting/backups) encrypts them. Never copy them anywhere unencrypted.
</Callout>
