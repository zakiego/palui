title: Introduction

---

Palui Agent is a personal AI assistant you run on your own server. It has one owner. You talk to it from WhatsApp, Telegram or the web chat in its dashboard, in Indonesian or English. It remembers things through recall, reminds you on time, runs scheduled jobs, and reaches your tools through MCP.

Channels, models, memory, tools and skills are all connectors. You add and manage them on the Connectors page in the dashboard.

<Callout type="info" title="Self-hosted, one owner">
  It's a personal agent you run yourself. Anyone other than the owner who messages the bot gets no reply, unless you give that chat an [agent](/docs/concepts/agents).
</Callout>

<ArchitectureDiagram>
  Messages arrive from three channels: WhatsApp, Telegram and the dashboard web chat. They flow into the runtime container, which holds the router, agent turns, the scheduler, the outbox and the connector supervisor. Next to it, the app container serves the dashboard, the REST API, authentication, the /health endpoint and database migrations. Both containers share one SQLite database on a single volume. Model providers, the recall memory service and MCP servers sit outside both containers and are reached over the network.
</ArchitectureDiagram>
