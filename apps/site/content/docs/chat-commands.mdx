title: Chat commands

Commands start with a slash. The router handles them before anything else, so they never reach the model and work even when every model connector is paused. Only the owner can use them. From anyone else they're dropped like any other message.

## Commands

| Command | What it does |
|---|---|
| `/connectors` | Lists every connector with its state. On Telegram each one has an inline button to flip it. |
| `/connectors on <id>` | Turns a connector on (resumes it). |
| `/connectors off <id>` | Pauses a connector. Credentials are kept. |
| `/new` | Starts a new session in this chat. recall auto-save runs for the one you just closed. |
| `/stop` | Aborts the turn that's running in this chat. |
| `/status` | Shows the model in use, tokens used today and connector states. |

`<id>` is the connector id shown by `/connectors`, for example `telegram`, `cliproxy` or `recall`.

### /connectors

```text
/connectors off recall
/connectors on recall
```

Connecting a new connector and removing one stay in the dashboard. Chat only pauses and resumes. Pausing applies from the next turn. See [Connectors](/docs/concepts/connectors).

### Switching off the channel you're on

`/connectors off telegram` sent from Telegram is allowed only when another channel or the dashboard is reachable. The reply tells you how to turn it back on. If nothing else is reachable, the command is refused, so you can't lock yourself out. The same rule applies to WhatsApp.

### When the model is off

If the only model connector is paused, any normal message gets this fixed reply:

```text
Model lagi off. Nyalakan: /connectors on cliproxy
```

(The model is off. Turn it on with this command.) Commands and plain reminders keep working.

## Approval answers

When a tool needs your approval, Palui sends a prompt. Answer it with:

| Channel | Approve | Deny |
|---|---|---|
| Telegram | The approve button | The deny button |
| WhatsApp | `ya` (yes) | `batal` (cancel) |
| Dashboard | Approve on the Chats page | Deny on the Chats page |

The router matches the answer to the pending approval, so it isn't sent to the model as a message. No answer within 10 minutes counts as a denial. See [Approvals](/docs/concepts/approvals).

## Reminder replies

A fired reminder offers Done and Snooze for 10m, 1h or tomorrow 09.00.

- Telegram: tap the inline buttons.
- WhatsApp: quote the reminder and reply.

```text
done
tunda 1j
```

(`tunda 1j` means "snooze 1 hour".) See [Reminders](/docs/concepts/reminders).
