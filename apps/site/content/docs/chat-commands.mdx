title: Chat commands
description: Reference for /connectors, /new, /stop, /status, /report and /agent, plus the approval and reminder replies Palui understands on every channel.
---

Commands start with a slash. The router handles them before anything else, so they never reach the model and work even when every model connector is paused. Only the owner can use them. From anyone else they're plain text: in a chat with an agent they go to the agent as a normal message, and anywhere else they're dropped.

## Commands

| Command | What it does |
|---|---|
| `/connectors` | Lists every connector with its state. On Telegram each one has an inline button to flip it. |
| `/connectors on <id>` | Turns a connector on (resumes it). |
| `/connectors off <id>` | Pauses a connector. Credentials are kept. |
| `/new` | Starts a new session in this chat. recall auto-save runs for the one you just closed. |
| `/stop` | Aborts the turn that's running in this chat. |
| `/status` | Shows the model in use, tokens used today and connector states. |
| `/report` | Replies with a debug snapshot of this chat to paste into a coding agent. |
| `/report <note>` | Same, with your note on what went wrong at the top. |
| `/agent` | Shows which agent answers in this chat and lists the agents. |
| `/agent <slug>` | Gives this chat that agent, allows it and starts a new session. See [Agents](/docs/concepts/agents). |
| `/agent off` | Goes back to Palui. Other people in this chat stop getting answers. |

`<id>` is the connector id shown by `/connectors`, for example `telegram`, `cliproxy` or `recall`.

### /connectors

```text
/connectors off recall
/connectors on recall
```

Connecting a new connector and removing one stay in the dashboard. Chat only pauses and resumes. Pausing applies from the next turn. See [Connectors](/docs/concepts/connectors).

### /report

```text
/report it answered the same message twice
```

The reply is plain text written for a coding agent, not for you. It holds:

- the chat, session and agent ids, the Palui version and a link to the chat in the dashboard
- the last five runs plus the runs behind the messages shown, each with its status, model, tokens and error, and any tool call that didn't finish ok
- the last ten messages, with the reason when one was stored but ignored
- outbox rows still waiting, and ones that failed in the last 24 hours
- warnings from the last 24 hours that name one of those runs, messages or outbox rows

Paste it into the agent working on your Palui checkout and it knows which rows to look at in `palui.db`. A long report can arrive as two messages; copy both, or use the id.

Every report has an id on its first line, like `rpt_...`, and the same text is saved in the `reports` table. If you only kept the id, that's enough: the agent can read the report back from the database.

In a group, or any chat other people are in, the report goes to your own chat with Palui and the group only sees the id.

The report quotes messages from the chat, other people's included, and the chat's address on the channel (on WhatsApp that's a phone number). Known token formats are masked, but read it before you paste it into a service you don't run.

### Switching off the channel you're on

`/connectors off telegram` sent from Telegram is allowed only when another channel or the dashboard is reachable. The reply tells you how to turn it back on. If nothing else is reachable, the command is refused, so you can't lock yourself out. The same rule applies to WhatsApp.

### When the model is off

If the only model connector is paused, any normal message gets this fixed reply:

```text
Model lagi off. Nyalakan: /connectors on cliproxy
```

(The model is off. Turn it on with this command.) Commands and plain reminders keep working.

## Approval answers

When a tool needs your approval, Palui sends a prompt. Answer it with:

| Channel | Approve | Deny |
|---|---|---|
| Telegram | The approve button | The deny button |
| WhatsApp | `ya` (yes) | `batal` (cancel) |
| Dashboard | Approve on the Chats page | Deny on the Chats page |

The router matches the answer to the pending approval, so it isn't sent to the model as a message. No answer within 10 minutes counts as a denial. See [Approvals](/docs/concepts/approvals).

## Reminder replies

A fired reminder offers Done and Snooze for 10m, 1h or tomorrow 09.00.

- Telegram: tap the inline buttons.
- WhatsApp: quote the reminder and reply.

```text
done
tunda 1j
```

(`tunda 1j` means "snooze 1 hour".) See [Reminders](/docs/concepts/reminders).
