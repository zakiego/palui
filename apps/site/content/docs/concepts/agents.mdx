title: Agents
description: Named personas with their own instructions, memory, daily cap and avatar, which you can put in groups and in other people's chats.

An agent is a persona Palui can answer as. Each one has its own persona text, standing instructions, recall container, daily token cap and avatar. Palui itself is the default agent, and it's the only one you start with.

Agents are how Palui answers people other than you. Put an agent in a group, or in a DM someone else started with Palui's number, and it answers them, the way @grok answers whoever tags it.

## The agent page

Open an agent on the Agents page and pick a section:

- Settings: avatar, name, persona, shared-chat rules, members and the daily cap.
- Chats: every chat it answers in, with the reply mode and "Answer here" for each.
- Instructions: what it always follows.
- Memory: its recall container, how many memories are in it, and when it last saved one.
- Tools: every tool it can use, grouped by connector with MCP servers marked, who can use them, and how often it ran each one this week.

## Palui stays yours

Palui is your personal agent. Its memory is your memory and its preferences are your personal data, so it never answers anyone else. A group you never gave an agent keeps the old rule: Palui answers only your own messages there.

## Give a chat an agent

1. Create the agent on the Agents page: a name, a slug like `chef`, and a persona.
2. Send `/agent chef` in that chat, or pick it for the chat on the Chats page.

That turns the chat on and starts a new session. The old one is saved to the old agent's memory first, the same as `/new`. `/agent off` goes back to Palui, and other people stop getting answers.

Someone who messages Palui in a chat you haven't set up gets no reply. The chat still shows up on the Chats page, marked Off, so you can set it up.

## Add Palui to a WhatsApp group

1. Add Palui's number to the group.
2. Mention it. It replies with the agents you have and the command for each.
3. Send one of them, like `/agent chef`.

A new WhatsApp group stays off until you do. Until then Palui answers your mentions there with that list and nothing else.

## Groups

In a group, an agent answers when someone @mentions Palui's number (or the agent's own bot) or replies to one of its messages. That applies to you too, except for commands. Once the group has an agent, it still reads the rest of the talk and keeps it as context, so a mention like "@agent what do you think?" knows what was just said. It never answers those messages on its own. Photos, files and voice notes from guests aren't downloaded, only their text.

To have it answer every message instead, send `/reply all` in the group, or pick "Every message" on the Chats page. `/reply mention` goes back. A Telegram bot only sees every message after you turn off its privacy mode in BotFather and add it to the group again.

Every message records who sent it. The model sees other people's messages as `[Name]: ...` and yours as `[Owner]: ...`, and it's told that only `[Owner]` lines come from you.

## Members

Members are people you trust with one agent: a partner, a family member, a teammate. They can use that agent's own data with it, which outsiders can't.

To add one, open the agent's Settings tab and use Members. Give them a name and one or more accounts: a WhatsApp number or a Telegram user id. You can pick from people who already wrote in a chat, or type the account in. The section saves at once. Palui has no members, and a member of one agent is a stranger to every other agent.

Adding a member doesn't open a DM with them. Their DM still has to be allowed and given the agent on the Chats page, like any other chat.

What a chat gets depends on who is in it:

| Who is in the chat | What the agent can use |
|---|---|
| Only you | Everything, with approvals as usual |
| You and members of this agent (a member's DM, or a WhatsApp group of only you and members) | Tools for that chat plus this agent's own data: its MCP servers, notes, contacts and memory. No approvals, nothing destructive |
| Anyone else | Only tools whose data stays in that chat, see below |

For a WhatsApp group, everyone in it has to be you or a member. The list is checked when a turn starts. It's read again when someone joins or leaves, and at least every 10 minutes. If the list can't be read, the group counts as having outsiders. So does a group where someone who isn't a member wrote earlier in the conversation, even after they've left, until the conversation starts over (`/new`). Telegram groups never count as members only, because a bot can't see who's in a group.

Members can read what the agent knows: its notes, contacts, memory and what was said in its other chats. They can't change its instructions, send messages to contacts, or approve anything. Commands, approvals and reminder buttons stay yours.

The agent's own write tools run for members without asking you, also in a turn that read a web page or another untrusted source. So a member, or a page the agent read for them, can make it add, change or rename things in its MCP servers, notes and contacts. Only add people you'd trust with that. A job that posts into a members chat runs under the same rules.

## What other people can make it do

This is about chats with someone who isn't you or a member: a group with an outsider in it, or a stranger's DM. What it gets depends on who can read the chat, not on who sent the message. It only gets tools whose data stays in that chat or that keep nothing: reminders, saved files, web search and web fetch. Your notes, contacts, memory, jobs, accounts and MCP servers never show up there, and the agent can't tell anyone they exist.

- One switch, Tools for other people: those tools, or none.
- No approvals there. A tool the chat gets runs right away, and destructive tools are never offered.
- Your own message in a group gets the same set as everyone else's. That includes Palui when you pick it for a group.
- A tool you set to "Ask first" or "Off" on the Tools tab isn't offered in shared chats at all.
- Sharing a saved file as a public link only works from your own chats.

Commands and reminder buttons work only for you. If someone else sends `/new` or `ya`, it's just a message to the agent.

Admin details stay out of shared chats. If the model is off or a budget is hit, people there get a short "can't answer right now" reply, and the details go to your DM.

## Memory

Each agent remembers in its own recall container, `agent-<slug>` unless you set another one. Palui keeps the recall connector's container.

Auto-save stores what other people said too, labeled with their name and the chat, so a group agent remembers who's who. That means anyone in a chat you allowed can put text into that agent's memory. It can never reach Palui's memory. Turns that read untrusted tool output are still skipped. See [Memory](/docs/concepts/memory).

Separate memory per chat gives each chat its own container (`agent-<slug>-c<hash>`), so what one customer says never comes up in another customer's chat. New agents start with it on. Turning it on or off later starts that agent from an empty memory, since the old container stays where it was.

Shared containers are read only. List up to 5 on the Memory tab, like a `kb-shop` container you fill yourself with product facts or an FAQ. Auto-recall reads them next to the agent's own memory and labels them as reference, never instructions. Palui's container is your memory, so no other agent can use it, read only or not.

An agent's recall tools follow the same rule. `search_memories` and the other read tools reach its own container and its shared ones, `add_memory` writes only to its own, and `forget_memory` only deletes a memory that's in its own container. Naming any other container is an error. Palui is locked the same way: its tools reach your memory and the shared containers on its Memory tab, never another agent's. To let Palui read an agent's memory, add that agent's container (like `agent-finansial`) to Palui's shared list. Flow steps and flow sources run with the flow's agent, so a flow gets the same limits.

## Daily cap

An agent with a daily token cap stops answering when it's used up, until midnight in your timezone. The chat gets one short notice that day. The global cap in Settings still applies on top.

## Its own Telegram bot

On Telegram an agent can have a bot of its own, so people add that bot to a group and @mention it by name. See [Agent bot](/docs/connectors/agent-bot). On WhatsApp every agent shares Palui's one number.

## Avatar

Upload a photo for an agent, or pick an icon and a color. The photo is cropped square and shrunk to 256 px in your browser before it's saved. The avatar shows on the Agents page and in the Chats agent picker.
